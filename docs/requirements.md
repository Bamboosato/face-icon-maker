# Face Icon Maker 要件

最終更新: 2026-07-16

## 1. 目的

集合写真から自分の顔を選び、プロフィール用PNGアイコンを短時間で作成できるブラウザアプリを提供する。

成功条件は「写真を選ぶ → 顔を選ぶ → PNGを保存する」を30秒以内で完了できることとする。

## 2. 制約

- 画像処理はブラウザ内で完結させる
- 写真・生成画像をサーバーへ送信しない
- バックエンド、データベース、認証、有料APIを使用しない
- スマートフォンを主対象とし、片手操作と大きなタップ領域を優先する
- 高度な画像編集機能より、顔の検出・選択・自動切り抜きを優先する

## 3. 機能要件

### 3.1 写真の読み込み

- JPEG / PNGを受け付ける
- 50 MB以上、50メガピクセル以上、一辺12,000ピクセル以上は明示的に拒否する
- EXIF Orientationを反映する
- 処理用画像は長辺最大3,000ピクセルへ縮小する

### 3.2 顔の検出と選択

- MediaPipeで複数の顔を自動検出する
- 検出顔に選択可能な枠を表示し、選択中の顔を強調する
- 検出感度を0.10〜0.95の範囲で調整できる
- 顔が見つからない場合は、感度変更または別の写真を案内する

### 3.3 自動切り抜きと編集

- 選択した顔の検出枠を基準に、約2.2倍の正方形領域を生成する
- 髪や頭部を含め、画像の端では範囲を画像内へ補正する
- 切り抜き元の最小サイズは96ピクセルとする
- 1:1のプレビュー上で位置と拡大率を調整できる

### 3.4 見た目の調整

- 形: 四角形 / 円形
- スタイル: 通常 / ピクセル / コミック / ペイント
- 背景: 元画像 / 透明 / 単色
- 背景除去は選択した顔の中心を起点にInteractive Segmenterで対象人物を分離する
- 対象人物と連結していない前景候補は除外する
- Interactive Segmenterが利用できない場合はSelfie Segmenterへフォールバックする

### 3.5 超解像

- 切り抜き元が512ピクセル未満の場合に任意で有効化できる
- 256ピクセル未満では推奨状態を表示する
- Real-ESRGAN x4で縦横4倍の中間画像を生成する
- 超解像を背景除去・スタイル処理より先に実行する
- 最終出力サイズは超解像の有無にかかわらず512 × 512ピクセルとする
- 処理中は進捗を表示し、同じ主ボタンからキャンセルできる
- 進捗表示によってボタン群や画面全体が上下に移動しない
- WebGPUを優先し、利用できない場合はWASMへフォールバックする
- 初期化・モデル取得・推論に失敗した場合は通常解像度で保存できる

### 3.6 出力

- 512 × 512ピクセルのPNGを生成する
- デスクトップでは保存、共有API対応端末では共有を優先する
- 共有できない場合はダウンロードへフォールバックする

## 4. 非機能要件

### 性能

- 顔検出開始: 通常環境で3秒以内を目標
- 顔選択の反応: 100ミリ秒以内を目標
- 通常PNG生成: 1秒以内を目標
- 超解像: 端末・ブラウザ・モデルキャッシュ・ネットワークに依存するため、時間固定の合否条件を設けず、進捗とキャンセル手段を保証する

### 信頼性

- 非同期処理の二重起動を防ぐ
- キャンセル後に古い処理結果で画面を更新しない
- モデル処理の失敗を通常保存の失敗へ波及させない
- 画像・Canvas・モデル関連リソースを不要になった時点で解放する

### 互換性

- 最新版Chrome / Edge / Safariを主対象とする
- WebGPU非対応環境でもWASMで超解像を試行できる
- 端末のメモリ不足やブラウザ制限時は、通常解像度で完了できる

### プライバシー

- 写真・切り抜き・生成PNGを外部へ送信しない
- モデルとWASMの取得にはネットワークを利用する
- UI上の説明は「処理はこの端末内で行われる」とし、完全オフラインと誤認させない

## 5. 状態遷移

1. 未選択
2. 画像読み込み中
3. 顔検出中
4. 顔選択
5. 編集
6. 通常保存中、または超解像準備・処理中
7. 保存 / 共有完了

エラーまたはキャンセル時は、画像や編集内容を失わず編集状態へ戻れること。

## 6. テスト観点

### 機能観点

- 正常系: 複数顔の検出、任意顔の選択、編集、通常保存、超解像保存
- 異常系: 未対応形式、上限超過、モデル取得失敗、WebGPU初期化失敗、推論失敗
- 境界値: 96 / 255 / 256 / 511 / 512ピクセル付近、入力上限、検出感度の上下限
- 状態遷移: 保存中のキャンセル、連続保存、編集へ戻る、最初からやり直す

### 非機能観点

- 低速回線での初回モデル取得
- WebGPUあり / なし、キャッシュあり / なし
- 高負荷・低メモリ端末でのフォールバック
- 非同期処理完了とキャンセルの競合

### データ観点

- 1人 / 複数人 / 顔なし
- 小さい顔、横顔、眼鏡、帽子、髪と背景が近い色
- 人物に接する木や衣服に似た背景
- 画像端の顔、縦長 / 横長、透過PNG

### UI観点

- タップ領域、選択状態、進捗、エラー文言
- 超解像ON/OFFでレイアウトが移動しないこと
- 処理中に主ボタンがキャンセルへ切り替わること
- 円形・透明背景のプレビューと出力一致

## 7. 受け入れ基準

- デスクトップChromeで基本フローが完了する
- iPhone 13 Pro Maxで超解像ONの保存を過度なストレスなく完了できる
- 背景の木など、選択人物と非連結の誤前景が出力へ残らない
- 超解像の有無で最終PNGの寸法が変わらない
- モデル処理に失敗しても通常解像度で保存できる
