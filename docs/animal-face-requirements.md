# アニマルフェイス追加要件

最終更新: 2026-09-07

## 1. 目的

既存の「画像アップロード → 顔選択 → 顔の切り抜き → PNG保存」フローに、選択した顔を動物風に加工する機能を追加する。

元画像と選択顔をブラウザ内で処理し、顔の位置・目・鼻・口・輪郭を静止画用の MediaPipe Face Landmarker で取得する。取得したランドマークを基準に、動物パーツの配置と軽量な2D変形を行う。

本機能は、本人を識別する「顔認識」ではなく、静止画に対する「顔ランドマーク検出」と「アニマルフェイス加工」である。

## 2. 対象範囲

### 2.1 対象

- 既存の顔選択・クロップ編集画面への機能追加
- 静止画に対する Face Landmarker の `IMAGE` モード利用
- 選択顔のランドマークを利用した動物風加工
- Cat / Dog / Fox / Bear のプリセット
- 既存の四角形・円形アイコン出力との併用
- 既存のPNG保存・共有処理との併用
- 写真、ランドマーク、中間Canvasのブラウザ内処理

### 2.2 対象外

- カメラ入力、動画入力、リアルタイム追従
- 60fps処理、Web Workerによる動画推論
- 本人識別、顔データベース、顔認証
- クラウドへの画像送信
- AI画像生成による人間の顔全体の動物置換
- 3Dモデル、クォータニオン、3Dアクセサリー
- 複数人への同時アニマルフェイス適用
- ユーザーアカウント、クラウド保存、データベース

## 3. 用語

| 用語 | 定義 |
|---|---|
| Face Detector | 既存の複数顔検出。顔選択用の矩形を返す |
| Face Landmarker | 選択顔の目・鼻・口・輪郭などのランドマークを返す静止画モデル |
| 参照領域 | 選択顔を含む、Face Landmarkerへ入力する画像領域 |
| 現在のCrop | ユーザーが編集している最終的な切り抜き領域 |
| アンカー | ランドマークから計算した耳・鼻・目・口などの配置基準 |
| アニマルフェイス | 元の顔を残しつつ、動物パーツと軽量な2D変形を加えた画像 |

## 4. ユーザーフロー

```text
画像アップロード
  ↓
既存Face Detectorによる顔検出
  ↓
顔を選択
  ↓
自動Cropを生成
  ↓
参照領域でFace Landmarkerを1回実行
  ↓
編集画面でアニマルフェイスを選択
  ↓
Crop・プリセット・既存エフェクトを調整
  ↓
512 × 512 PNGを保存または共有
```

Face Landmarkerの結果は処理用画像の座標へ変換して保持する。ユーザーがCropを移動・拡大しても、同じランドマークを現在のCropへ再マッピングし、不要な再推論を行わない。

## 5. 機能要件

### FR-ANIMAL-001 Face Landmarkerの実行

- 顔選択後、選択顔を含む参照領域に対してFace Landmarkerを実行する。
- 実行モードは `IMAGE` とする。
- 現行の `@mediapipe/tasks-vision` を利用する。
- 現行のFace Detectorを顔選択用途として維持する。
- Face Landmarkerが期待するランドマーク数を返さない場合は、加工を中止してエラー状態にする。

### FR-ANIMAL-002 ランドマークの座標変換

- Face Landmarkerの正規化座標を参照領域のピクセル座標へ変換する。
- 参照領域の座標を、向き補正・縮小済みの処理用画像の座標へ変換する。
- 現在のCropへ再マッピングできること。
- x / y / z に `NaN`、無限大、未定義値が含まれる場合は不正データとして扱う。
- z座標は現実空間の距離として扱わず、相対的な深度値としてのみ利用する。

### FR-ANIMAL-003 アンカー計算

- 目、鼻、口、頬、輪郭、額の複数ランドマークからアンカーを計算する。
- 単一ランドマークだけに依存せず、複数点の平均・範囲・方向を使用する。
- 左右の目の位置から顔のロール角を計算する。
- 顔幅、目の間隔、鼻の幅を相対尺度として利用する。
- 顔がCrop外へ移動した場合、パーツを無制限に描画せず、警告または非表示にする。

### FR-ANIMAL-004 アニマルフェイスプリセット

- 「なし」を含む次のプリセットを提供する。
  - Cat
  - Dog
  - Fox
  - Bear
- プリセット変更時はFace Landmarkerを再実行しない。
- プリセット変更後、プレビューへ反映する。
- リセット時は「なし」に戻す。
- プリセットのパラメータと素材は、UIコンポーネント内に直接記述しない。

### FR-ANIMAL-005 動物パーツの配置

- 透明背景のローカル素材を利用する。
- 耳は顔上部、鼻は鼻アンカー、ヒゲ・口元は鼻と口のアンカーを基準に配置する。
- 顔の傾きに合わせて素材を回転する。
- 顔幅または目の間隔に応じて素材を拡大・縮小する。
- 配置・回転・拡大縮小の処理は、プレビューとPNG保存で共通化する。

### FR-ANIMAL-006 軽量な2D変形

- 必要な部位だけを局所変形し、顔全体を不自然に引き伸ばさない。
- 対象部位は目元、鼻、口元、頬を基本とする。
- 変形領域の境界はフェザー処理し、矩形の継ぎ目を出さない。
- 変形量はプリセット設定で管理する。
- 変形処理に失敗した場合でも、元のCropを破壊しない。

### FR-ANIMAL-007 既存機能との組み合わせ

- 四角形・円形の出力に対応する。
- 既存の背景処理、色、ペイント、ピクセル系エフェクトと組み合わせられる。
- アニマルフェイスのON/OFFで出力サイズは変わらない。
- アニマルフェイスが無効の場合、既存出力と同一の結果になる。

### FR-ANIMAL-008 保存・共有

- 出力は既存仕様どおり512 × 512ピクセルのPNGとする。
- プレビューと保存PNGで、プリセット、位置、回転、変形が一致する。
- Face Landmarkerの失敗時も、元のCropを保存できる。
- 保存中に処理状態を表示し、二重保存を防止する。

## 6. データ・アセット要件

### 6.1 プリセットデータ

プリセットは次の情報を持つ設定データとする。

- `id`
- 表示名
- 目元・鼻・口元・頬の変形パラメータ
- 耳・鼻・ヒゲなどの素材参照
- 素材ごとのアンカー、基準サイズ、基準回転

### 6.2 素材

- 素材はアプリに同梱する。
- 外部URLから実行時に動物素材を取得しない。
- 透明背景を保持する。
- 素材のバージョンまたはハッシュを管理できる構成にする。

### 6.3 プライバシー

- 元画像、切り抜き画像、ランドマークをサーバーへ送信しない。
- Face Landmarkerの結果を永続保存しない。
- ページ離脱またはリセット時に不要なCanvas、Object URL、モデル参照を解放する。
- モデル配信を同一オリジンの静的アセットに寄せ、初回取得の再現性を確保する。

## 7. 非機能要件

### 性能

- Face Landmarkerの初回実行は、通常環境で2秒以内を目標とする。
- モデル読み込み済みのプリセット変更・Crop変更は100ms以内を目標とする。
- アニマルフェイス追加による512×512出力の追加処理時間は100ms以内を目標とする。
- 既存の顔検出開始3秒以内、PNG出力1秒以内の目標を悪化させない。

### 信頼性

- Face Landmarkerの読み込み失敗、推論失敗、素材読み込み失敗を個別に判定できる。
- 非同期処理の古い結果で、新しいCropやプリセットを上書きしない。
- エラー時も元のCropと編集内容を保持する。
- 同一画像で同じ設定を使った場合、毎回同じ出力になる。

### 互換性

- 既存の対象ブラウザを維持する。
- WebGLやカメラAPIを必須にしない。
- Canvas 2Dで基本機能が動作する構成とする。

## 8. 状態遷移

```text
select
  ↓ 顔選択
landmarker-loading
  ↓ モデル準備完了
landmarking
  ↓ 成功
edit-ready
  ├─ Crop変更 → edit-ready
  ├─ プリセット変更 → edit-ready
  ├─ 保存 → saving → saved
  └─ 戻る → select

landmarker-loading / landmarking
  └─ 失敗 → landmark-error → 元のCropでeditへ戻る
```

モデル処理のキャンセルまたは失敗時は、画像やCropを失わず編集状態へ戻れること。

## 9. テスト設計

### 9.1 先に確認する観点

- 機能：検出、座標変換、アンカー、変形、素材配置、保存
- 非機能：処理時間、メモリ、再現性、モデルキャッシュ、ブラウザ差
- データ：1人・複数人・小さい顔・横顔・傾き・画像端・欠損値
- UI：処理中表示、選択状態、タップ領域、エラー、プレビューと保存結果
- 状態：連続操作、戻る、リセット、保存中操作、古い非同期結果

### 9.2 正常系

- 1人の顔を選択し、Face Landmarkerが正常に完了する
- 複数人の画像から選択顔だけを加工する
- 4プリセットを切り替える
- Crop変更後もアンカーが顔に追従する
- 円形・四角形、既存エフェクトとの組み合わせで保存する

### 9.3 異常系

- モデルが取得できない
- Face Landmarkerが顔を返さない
- ランドマーク数が不正
- 座標にNaNや無限大が含まれる
- 素材が読み込めない
- CanvasまたはPNG生成に失敗する

### 9.4 境界値

- 顔が画像端に接している
- 極端に小さい顔、大きい顔
- 正面、30度程度の斜め顔、横顔
- 顔のロール角が大きい画像
- Cropを顔から大きく外した場合
- 画像の縦長、横長、透過PNG

### 9.5 状態遷移・競合

- Landmarker実行中に戻る
- Landmarker実行中にリセットする
- 実行中に別の顔を選択する
- 実行中にプリセットを変更する
- Cropを短時間に連続変更する
- 保存中に再度保存する

### 9.6 証跡

- ブラウザ、OS、画像条件、モデルキャッシュ状態を記録する
- モデル処理時間、描画時間、PNG生成時間を記録する
- 失敗時は状態、エラーコード、再現手順、スクリーンショットを残す
- 実機確認では同一端末へのテストを並列実行しない

## 10. 受け入れ基準

- 既存の顔選択・Crop・保存フローが回帰しない。
- 選択顔に対して静止画Face Landmarkerが実行される。
- ランドマークを使って、顔の傾きと大きさに追従した配置ができる。
- Cat / Dog / Fox / Bearを切り替えられる。
- プレビューと保存PNGの結果が一致する。
- Face Landmarkerが失敗しても、元のCropを保存できる。
- 元画像やランドマークが外部へ送信されない。
- 既存の512×512 PNG出力仕様を維持する。
