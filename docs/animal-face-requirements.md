# アニマルフェイス追加要件

最終更新: 2026-10-06

2026-09-07の追加要件を現行コードと照合した。以下は実装済みの範囲と品質目標を示す。当初案との差分は末尾に残し、テスト設計を実施済みの結果とは扱わない。

## 1. 目的と範囲

既存の「画像アップロード → 顔選択 → Crop編集 → PNG保存」へ、選択顔を動物風に装飾する機能を追加する。静止画用MediaPipe Face Landmarkerで顔の目・鼻・口・輪郭を取得し、元の顔を残してSVGとCanvasの目元・口元装飾を合成する。

本人識別や顔認証ではない。画像・ランドマークはブラウザ内で扱い、永続保存やサーバー送信を行わない。既存の形・背景・スタイル・超解像・PNG保存・共有と組み合わせる。

対象外:

- カメラ、動画、リアルタイム追従、60fps、動画用Worker
- 顔認証、顔データベース、クラウド保存
- AI画像生成による顔全体の動物置換
- 3Dモデル、3Dアクセサリー
- 複数人への同時加工
- 顔画素の局所ワープ、頬の変形、フェザー付き変形領域

## 2. 用語

| 用語 | 定義 |
|---|---|
| Face Detector | 写真全体の複数顔を検出し、選択用のFaceBoxを返す |
| Face Landmarker | 選択顔を含む静止画参照領域でランドマーク候補を返す |
| 参照領域 | 顔選択時の自動Crop。初回解析に利用する |
| 現在のCrop | ユーザーが編集した最終的な切り抜き領域 |
| アンカー | 複数ランドマークから計算する目・鼻・口の位置、顔幅、傾き |
| アニマルフェイス | 顔を残し、動物SVGと目元・口元装飾を加えた画像 |

## 3. フロー

```text
Face Detector → 顔選択 → 自動Crop → 編集画面
  → Face Landmarkerで参照領域を解析
  → 最大3顔の候補から選択顔に最も近い結果を採用
  → Animal faceを選択 → Crop・見た目を調整
  → 保存時のみ任意の超解像とランドマーク再マッピング
  → 512 × 512 PNGの保存 / 共有
```

解析は顔選択ごとに行う。ランドマークのx/yを処理用画像座標で保持し、Cropやプリセットを変更しても再推論しない。別の顔を選ぶとCrop・アニマル設定を初期化して解析し直す。形・スタイル・背景は保持する。

## 4. 機能要件

### FR-ANIMAL-001 静止画解析

- 既存Face Detectorを維持し、顔選択後にFace Landmarkerを実行する
- `@mediapipe/tasks-vision` の `IMAGE` モード、`numFaces: 3` を利用する
- 参照領域内に隣人が含まれても、輪郭点から計算した中心が選択顔中心に最も近い候補を採用する
- ランドマークが得られない、または468点未満なら解析失敗とする
- 解析中・失敗時はアニマル選択を無効化する。通常のCrop編集・保存は継続できる

### FR-ANIMAL-002 座標変換

- 正規化座標を参照領域経由で処理用画像のx/yへ変換する
- 現在のCropとCanvas寸法で描画座標へ再マッピングする
- 使用するランドマークのx/y/zが欠損・NaN・無限大の場合は、その幾何計算を行わない
- zは元の相対深度値として保持するが、配置計算には使用しない
- 超解像保存時はCrop座標を超解像中間画像へ変換する

### FR-ANIMAL-003 アンカー

- 目、鼻、口は複数ランドマークの平均、顔幅・高さは輪郭点間の距離で求める
- 左右の目からロール角と目の間隔を求める
- 顔幅・目の間隔をSVGや装飾の相対尺度として利用する
- Crop外の描画はCanvas範囲で切れる。専用警告や耳を自動縮小する機能はない

### FR-ANIMAL-004 プリセット

Noneと次の12種類を提供する。

| 表示名 | ID |
|---|---|
| Cat | cat |
| Dog | dog |
| Fox | fox |
| Bear | bear |
| Elephant | elephant |
| Lion | lion |
| Rabbit | rabbit |
| Panda | panda |
| Raccoon | raccoon |
| Tiger | tiger |
| Wolf | wolf |
| Hamster | hamster |

- プリセット・素材・装飾パラメータは `src/config/animalPresets.ts` に置く
- プリセット変更は再推論せずプレビューへ反映する
- None、別顔選択、Start Overでアニマル効果を解除する
- 編集から保存、保存から編集へ戻る操作では選択を保持する

### FR-ANIMAL-005 SVGとCanvas装飾

- 透明背景のローカルSVGをプリセットごとに1枚用意する
- 鼻アンカーを基準にSVG全体を置き、顔幅でサイズ、目の位置で傾きを決める
- 目元は曲線、口元は半透明の楕円をCanvasへ描く
- 素材が読めない場合はそのアニマル効果を省略して通常描画を継続する

### FR-ANIMAL-006 描画パラメータ

現行の `warp` は `eyeScale / noseScale / muzzleScale` の3値で、装飾の大きさ・濃さを調整する。名前にwarpが含まれるが、元画像の画素を変形する処理はない。当初案の局所2D変形は未実装である。

### FR-ANIMAL-007 既存機能との併用

- 四角形 / 円形、元背景 / 透明 / 単色、4スタイル、超解像と併用する
- アニマル素材は背景合成後に描画する
- スタイルとの順序は[設計](animal-face-architecture.md)の分岐に従う
- Noneまたはランドマークなしの場合はアニマル描画を省略する

### FR-ANIMAL-008 保存・共有

- PNGは512 × 512固定で、保存・共有の経路は既存処理を使う
- プレビューと保存は同じ描画関数と設定を利用する
- プレビューは192 × 192で超解像前、保存は512 × 512で必要に応じ超解像後のため、完全な画素一致は保証しない
- Landmarkerの失敗時もアニマルなしのCropを保存できる
- 保存中は再保存・編集・再開始操作を無効化する。超解像時は主操作をキャンセルに切り替える

## 5. アセット・プライバシー・ライフサイクル

- モデルは `/models/face_landmarker.task`、WASMは `/mediapipe/wasm`、SVGは `/animal/*.svg` として同一オリジンから配布する
- 初期化Promise、素材読み込みPromiseを共有してページ内で再利用する
- ランドマークの `modelVersion` は `"1"`。SVGごとの独立したハッシュやバージョン管理はない
- 戻る・リセット・別顔選択でリクエスト番号を更新し、古い解析結果を破棄する
- Start Overで画像URL・編集内容・ランドマークを破棄するが、モデルと素材のキャッシュは維持する
- モデルのcloseや失敗Promiseのクリアは、通常UIのリセットには実装されていない

## 6. 非機能目標

- 初回Face Landmarker解析は通常環境で2秒以内を目標にする
- 解析済みのCrop・プリセット変更は100ms以内、出力の追加処理も100ms以内を目標にする
- 既存の顔検出開始3秒以内、通常PNG生成1秒以内の目標を維持する
- Canvas 2Dの装飾にWebGL・カメラAPIを必須としない
- 端末・OS・ブラウザ・ネットワーク・モデルキャッシュの差を考慮する

これらは品質目標であり、全条件で計測・達成済みではない。

## 7. 状態とエラー

顔選択後は解析完了を待たず編集画面を表示し、`Analyzing face` とプリセットの無効状態で準備中を示す。成功時は選択可能にし、失敗時は元Cropを保持して通常保存が可能なメッセージを表示する。失敗後もプリセット欄の文言は準備中表示のままで、専用の再試行ボタンはない。

戻る・別顔選択後の古い解析結果は破棄する。Crop変更やプリセット変更では再解析しない。Landmarker推論専用のキャンセルボタンはなく、戻る操作は結果の反映を取り消す。

素材読み込み失敗・無効アンカーは効果を省略するが専用エラーは表示しない。Canvas・PNG生成の一般的な失敗を必ず元Cropへ復旧できる保証はない。

## 8. テスト設計

### 先に確認する観点

- 機能: 候補選択、座標変換、アンカー、12プリセット、装飾、保存・共有
- 非機能: 処理時間、メモリ、キャッシュ、ブラウザ差、遅延・取得失敗
- データ: 1人 / 複数人、小さい顔、横顔、傾き、画像端、欠損値
- UI: 無効状態、選択表示、タップ領域、エラー、プレビューと出力
- 状態: 連続操作、戻る、別顔選択、リセット、古い結果、超解像キャンセル

### 正常系

- 選択顔中心に近い候補が採用され、隣人の顔へ装飾が移らない
- 全12種類とNoneを切り替え、Noneで効果が消える
- Crop変更後も再推論せずアンカーが再配置される
- 四角形 / 円形、背景・スタイル、超解像との組み合わせで保存できる

### 異常系

- モデル取得・推論失敗でも通常Cropを保存できる
- 候補なし・468点未満・必要座標のNaN / 無限大を扱える
- 素材取得失敗で通常描画を継続する
- Canvas・PNG失敗を通常の保存エラーと切り分ける

### 境界値

- 顔の大小、画像端、横顔、ロール角、縦長 / 横長、透過PNG
- Cropを顔から外す、耳がCropや円形マスクに接する
- 255 / 256 / 511 / 512px付近で超解像の条件と再配置を確認する

### 状態遷移・競合

- 解析中の戻る・リセット・別顔選択で古い結果が反映されない
- Crop連続変更、保存→編集、再保存で設定と解析結果を保つ
- 最終タイル付近のキャンセルを含め、キャンセル後の保存開始を確認する
- ページ再読み込みでユーザーデータが残らない

### 証跡と範囲

ブラウザ・OS・端末、画像条件、モデルキャッシュ、操作順、コンソール・ネットワーク・PNGを記録する。同一実機へ並列スクリプトを実行しない。既存自動テストは幾何・候補選択・プリセット設定を対象とし、描画・保存・モデル実行・状態遷移の保証は別途確認する。[今回の確認記録](documentation-audit.md)に実施・未実施範囲を記載する。

## 9. 当初案との差分・継続課題

- 当初4種類から12種類に拡張し、選択UIはボタン列ではなくSVG付きドロップダウンになった
- `numFaces: 1` ではなく3と候補選択を採用した
- 局所画素ワープ、頬変形、フェザー、部位別素材アンカーは未実装。必要性の判断と追加実装は別の作業とする
- Crop外の警告・耳の自動縮小、解析失敗後の専用UI、モデル・素材の明示的な再試行・解放は未実装
- 実機性能、低速回線、各ブラウザ、全プリセットの描画・超解像併用の最新検証は継続対象
