## テスト実行順

1. 単体テストで計算・境界・マスク処理を確認
2. デスクトップChromeで通常保存とフォールバックを確認
3. 同じ写真で超解像OFF / ONを比較
4. 実機は1台ずつ、通常→超解像→キャンセル→再実行の順で確認
5. ログ、スクリーンショット、入力条件、端末・OS・ブラウザ版を記録

同一実機へ複数の自動化スクリプトを並列実行しない。
