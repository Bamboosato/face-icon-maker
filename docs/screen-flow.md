# 画面遷移

最終更新: 2026-07-16

## 方針

主経路は「写真を選ぶ → 顔を選ぶ → 保存」の3操作に近づける。高度な設定は編集画面へ集約し、必須操作にしない。

## S01 写真を選ぶ

表示:

- アプリの説明
- 写真選択ボタン
- 端末内処理であることの案内

遷移:

- 有効なJPEG / PNG → 読み込み・顔検出 → S02
- 未対応形式・上限超過・読込失敗 → エラー表示、S01を維持

## S02 顔を選ぶ

表示:

- 集合写真
- 検出された各顔の選択枠
- 選択中の顔の強調
- 検出感度
- 写真の再選択

遷移:

- 顔を選択 → 自動切り抜きを生成 → S03
- 顔なし → 感度変更または別写真を案内
- 写真を再選択 → 状態を初期化して再検出

## S03 編集

表示:

- 1:1プレビュー
- 位置・拡大率の調整
- 四角形 / 円形
- 通常 / ピクセル / コミック / ペイント
- 元背景 / 透明 / 単色背景
- 保存へ進む
- 最初からやり直す

背景変更時:

- 選択顔を起点に人物を分離する
- 失敗時は汎用人物分離へフォールバックする
- 処理失敗時は元背景を維持し、再試行可能にする

遷移:

- 保存へ進む → S04
- 最初からやり直す → 確認後にS01

## S04 保存

表示:

- 最終プレビュー
- 切り抜き元が512ピクセル未満の場合だけ超解像の選択
- 256ピクセル未満の場合は超解像を推奨
- 保存 / 共有
- 編集へ戻る
- 最初からやり直す

超解像OFF:

- 現在の編集内容から512 × 512 PNGを生成する

超解像ON:

1. 主ボタンを「Cancel enhancement」へ切り替える
2. 補助説明の領域に準備・処理状況を表示する
3. 超解像後に背景分離、スタイル、形状を再適用する
4. 512 × 512 PNGを保存または共有する

進捗文言やキャンセル操作のために新しい行・ボタンを追加せず、カードと操作領域の高さを維持して画面のガタつきを防ぐ。

異常・キャンセル:

- キャンセル → 編集内容を保持してS04へ戻る
- WebGPU失敗 → WASMで継続
- 超解像失敗 → 通常解像度での保存を案内
- 共有失敗 → ダウンロードへフォールバック

## 状態遷移で重点確認する点

- 読み込み中に別画像を選び直した場合、古い検出結果を表示しない
- 背景分離中に設定を変えた場合、最後の設定だけを反映する
- 超解像をキャンセルした直後に完了しても、保存を勝手に開始しない
- 保存後に編集へ戻っても選択顔・切り抜き・見た目を保持する
- 最初からやり直した場合はモデルキャッシュ以外のユーザーデータを破棄する
