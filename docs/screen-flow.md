# 画面遷移

最終更新: 2026-10-06

`src/App.tsx` の `upload / select / edit / download` に対応する。主経路は「写真 → 顔 → PNG保存」。任意の加工は編集画面へ集約する。以下は現行の挙動であり、競合・互換性の検証範囲は[確認記録](documentation-audit.md)を参照。

## S01 写真を選ぶ（upload）

表示:

- アプリ説明、写真選択ボタン、JPEG / PNGのドロップ領域
- 検出感度（初期値0.50、0.10〜0.95、0.05刻み）
- 端末内処理の案内

遷移:

- 有効な入力 → 準備・検出 → 顔ありならS02
- 未対応形式・上限超過・読み込み失敗 → エラー、S01を維持
- 初回検出で顔なし・検出失敗 → エラー、S01へ戻る

準備・検出中は写真選択と感度を無効化する。顔なしでも手動Cropへは進まない。

## S02 顔を選ぶ（select）

表示:

- 写真、番号付き顔枠、検出件数、10顔以上の場合の案内
- 検出感度、Redetect、Back
- 選択中の枠の保持・強調は未実装。枠を押すと編集画面へ移る

遷移:

- 顔を選択 → 自動Crop・アニマル初期化 → S03でランドマーク解析
- 感度変更 / Redetect → 再検出。0件ならS02を維持する
- Back → 画像・編集内容を破棄してS01。検出感度は保持する

再検出中は感度が無効になるが、Redetectと顔枠は一律無効にはならない。古い検出結果の破棄と競合防止は継続課題。

## S03 編集（edit）

表示:

- Back、1:1 Cropの移動・拡大縮小、192 × 192プレビュー
- Animal face: None + 12種類のSVG付きドロップダウン
- Square / Circle
- Natural / Pixel / Comic / Paint
- ピクセル粒度Small / Medium / Large、ペイント強さ0〜100
- Original / Clear / Color（4色）
- Done

顔選択直後:

- 編集画面を表示したまま `Analyzing face` を表示
- ランドマークなしの間はAnimal faceを無効化。通常編集とDoneは可能
- 成功時はプリセット操作を有効化。Crop変更では再推論せず座標を再計算
- 失敗時はアニマルをNoneに戻し、通常保存できる旨を表示。専用の再試行操作はない
- プリセット欄は解析失敗時も準備中ヒントを表示するため、失敗時文言は改善対象

背景変更時:

- 選択顔の中心を起点に人物分離を行い、失敗時はSelfieへ戻る
- 両モデルに失敗した場合は元背景を残す。専用エラー・再試行ボタンはない

遷移:

- Done → S04
- Back → S02。解析中の古い結果は無効化する
- S02から別顔を選択 → Crop・アニマルを初期化。形・スタイル・背景は保持

S03にStart Overはない。S02のBackから写真選択へ戻る。

## S04 保存（download）

表示:

- Done、プレビュー、出力ファイル名
- Crop短辺512px未満の場合に超解像選択、256px未満で推奨
- スマートフォン判定時はShare PNG、それ以外はSave PNG
- Edit、Start Over

超解像は既定OFF。`VITE_SUPER_RESOLUTION_ENABLED=false` なら選択肢を表示しない。プレビューは192 × 192の超解像前画像で、保存PNGは512 × 512。背景マスクの入力解像度も異なるため、画素の完全一致を保証しない。

超解像OFF:

- 現在の編集設定で512 × 512 PNGを生成して保存 / 共有

超解像ON:

1. 主操作を `Cancel enhancement` に変更し、既存の補助説明欄で進捗を表示
2. Cropの超解像とランドマーク再マッピングを実行
3. 共通描画で背景・アニマル・スタイル・形状を適用し、512 PNGを生成
4. 保存 / 共有

追加ボタンや進捗行を挿入せず、説明領域を固定して操作領域の移動を抑える。保存中はEdit・Start Over・超解像設定を無効化する。通常保存中は主ボタンも無効化し、超解像中はキャンセルを受け付ける。

異常・キャンセル:

- 超解像のキャンセル → 編集設定を保持してS04を維持
- WebGPUの読み込み・コンパイル失敗 → WASMで再試行
- 超解像失敗 → 通常画像のPNGで保存 / 共有し、警告を返す
- 共有API非対応・キャンセル以外の共有失敗 → ダウンロード
- 共有シートのキャンセル → ダウンロードせず終了
- PNG生成失敗 → S04を維持して再操作可能。通常保存失敗時の専用エラー表示は継続課題

キャンセル確認は超解像開始時・モデル準備後・各タイル開始時。取得・推論の即時中断と、最終タイル後〜保存開始までのキャンセル競合防止は保証しない。

遷移:

- Edit → S03で画像・選択顔・Crop・見た目を保持。S04への再入場では超解像選択はOFF
- Start Over → 確認ダイアログなしでS01へ。検出感度を保持し、他のユーザー状態は初期化。モデル・素材キャッシュは再利用

## 状態遷移の継続確認

- 再検出中のBack・顔選択・Redetect連打で古い結果が反映されないか
- 解析中のBack・別顔選択で古いランドマークが反映されないか
- 背景・Crop連続変更で最後のプレビューだけを表示するか
- 超解像の最終タイル付近のキャンセルで保存を開始しないか
- 保存→編集→保存で編集設定を保持し、再開始・再読み込みでは破棄するか
- 共有キャンセル・モデル失敗後の再実行が通し操作で成立するか

これらは検証観点であり、全環境で確認済みの保証ではない。
